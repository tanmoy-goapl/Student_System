## Answer Guide 

### Problem 1 – Conceptual Understanding 

* Over‑fitting occurs when a model captures noise in the training data, leading to low training loss but poor performance on new data. 
* A validation set provides an **unbiased estimate** of how the model will behave on unseen examples because it is not used during parameter updates. 
* Model selection (choosing hyper‑parameters, feature sets, algorithm type) relies on comparing validation performance; without it we would be tempted to pick the model that simply memorises the training set. 
* Cross‑validation repeats this idea by rotating the validation fold, giving a more stable estimate when data are limited.

### Problem 3 – Debugging a Classification Script 

1. **Cause** – The target vector `yₜrain` (and consequently `yₜest`) contains continuous values (e.g., 0.0, 1.0, 2.0) instead of discrete class labels. LogisticRegression expects categorical labels. 

2. **Fix** – Convert the targets to integer class labels before fitting, e.g.:

```python
y_train_int = y_train.astype(int)
y_test_int  = y_test.astype(int)

model.fit(X_train, y_train_int)
y_pred = model.predict(X_test)
accuracy = (y_pred == y_test_int).mean()
```

If the problem is that the labels are strings, encode them with `LabelEncoder` first.

### Problem 4 – Choosing a Loss Function 

* **MSE** 
 * Advantages: Differentiable everywhere, gives a closed‑form solution for linear regression, heavily penalises large errors, which can lead to more accurate predictions when outliers are genuine. 
 * Disadvantages: Sensitive to outliers; a single extreme price can dominate the loss and pull the fitted line away from the bulk of the data. 

* **MAE** 
 * Advantages: Linear penalty on errors, so each observation contributes proportionally; robust to outliers because large deviations are not squared. 
 * Disadvantages: Not differentiable at zero, which can make optimization slower (requires sub‑gradient methods); may produce a model that under‑estimates the impact of rare but important high‑price houses. 

* **Practical guidance** – If the housing price distribution has many extreme values (luxury homes) that you do **not** want to dominate the model, MAE is safer. If you care about minimizing overall squared error (e.g., for financial risk calculations), MSE is appropriate.
