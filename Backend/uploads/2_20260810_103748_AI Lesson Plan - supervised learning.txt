## 3. Core Concepts – Detailed Explanation  

### 3.1 Formal Problem Statement  

- **Input space** \(\mathcal{X}\): feature vectors \(x \in \mathbb{R}^d\) (or other structured representations).  
- **Output space** \(\mathcal{Y}\):  
  - *Regression*: \(\mathcal{Y} = \mathbb{R}\) (continuous).  
  - *Classification*: \(\mathcal{Y} = \{1,\dots,K\}\) (discrete labels).  
- **Training set** \(\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n\) drawn i.i.d. from an unknown distribution \(P_{XY}\).  
- **Hypothesis class** \(\mathcal{H} = \{h_\theta : \mathcal{X}\to\mathcal{Y}\}\) parameterised by \(\theta\).  
- **Loss function** \(\ell(y, \hat y)\) quantifies error for a single example (e.g., squared loss, cross‑entropy).  
- **Empirical risk** \( \hat R(\theta) = \frac{1}{n}\sum_{i=1}^n \ell(y_i, h_\theta(x_i))\).  
- **Goal**: Find \(\theta^\* = \arg\min_{\theta\in\Theta} \hat R(\theta)\) (or regularised version).  

### 3.2 Regression vs Classification  

| Aspect | Regression | Classification |
|--------|------------|----------------|
| Output | Real‑valued scalar or vector | Discrete class label (binary or multi‑class) |
| Typical loss | **MSE**, **MAE**, Huber | **0‑1 loss**, **cross‑entropy**, **hinge** |
| Evaluation metrics | RMSE, R², MAE | Accuracy, Precision, Recall, F1, ROC‑AUC |
| Example algorithms | Linear regression, SVR, Decision trees, Neural nets | Logistic regression, SVM, k‑NN, Random Forest, CNNs |

### 3.3 Supervised Learning Pipeline  

1. **Data acquisition** – source, labeling strategy, ethics.  
2. **Pre‑processing** – cleaning, handling missing values, feature scaling, encoding categorical variables.  
3. **Exploratory Data Analysis (EDA)** – visualise distributions, correlations, class imbalance.  
4. **Model selection** – choose hypothesis class, consider capacity & interpretability.  
5. **Training** – optimisation (gradient descent, closed‑form, convex solvers).  
6. **Validation** – hold‑out set or K‑fold cross‑validation, hyper‑parameter tuning (grid/random search).  
7. **Testing** – final unbiased performance estimate.  
8. **Deployment** – model serialization, monitoring for data drift.  

### 3.4 Over‑fitting, Under‑fitting & Regularisation  

- **Under‑fitting**: high bias, model too simple → poor training & test performance.  
- **Over‑fitting**: high variance, model memorises noise → low training error, high test error.  
- **Regularisation**: add penalty \( \lambda \Omega(\theta) \) (e.g., L2 ridge, L1 Lasso) to control complexity.  

### 3.5 Common Algorithms (Brief Overview)  

| Algorithm | Core Idea | Typical Use‑case |
|-----------|-----------|------------------|
| **Linear Regression** | Solve normal equations or gradient descent for \(\hat y = w^\top x + b\). | Predict house prices, stock returns. |
| **Logistic Regression** | Model \(P(y=1|x)=\sigma(w^\top x + b)\) with sigmoid; maximise likelihood. | Binary classification (spam vs ham). |
| **k‑Nearest Neighbours** | Non‑parametric, label by majority of nearest neighbours. | Low‑dimensional, interpretable tasks. |
| **Support Vector Machine** | Maximise margin, optionally kernelise. | Text categorisation, image recognition (small datasets). |
| **Decision Trees / Random Forests** | Recursive partitioning, ensemble averaging. | Tabular data, handling mixed types. |
| **Neural Networks (MLP)** | Stacked linear+non‑linear layers, trained by back‑prop. | Complex, high‑dimensional data (images, speech). |

## 5. In‑Class Activities  

### 5.1 Metric Computation Exercise (8 min)  

- Hand out a small confusion matrix (e.g., TP=40, FP=10, FN=5, TN=45).  
- Ask pairs to compute **accuracy**, **precision**, **recall**, **F1**, and **specificity** on a mini‑whiteboard.  
- Quick debrief: emphasise trade‑offs and when each metric matters.

### 5.2 Live Coding Lab (10 min)  

**Goal:** Train a logistic regression on the Iris dataset (binary version: *setosa* vs *non‑setosa*).  

```python
import numpy as np, pandas as pd
from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, classification_report

# Load data
iris = datasets.load_iris()
X = iris.data[iris.target != 2]          # keep only first two classes
y = (iris.target[iris.target != 2] == 0).astype(int)  # setosa = 1

# Split & scale
X_train, X_test, y_train, y_test = train_test_split(X, y,
                                                    test_size=0.3,
                                                    random_state=42,
                                                    stratify=y)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)

# Train
clf = LogisticRegression()
clf.fit(X_train, y_train)

# Predict & evaluate
y_pred = clf.predict(X_test)
print('Accuracy:', accuracy_score(y_test, y_pred))
print(classification_report(y_test, y_pred))
```

- Instructor runs the code, points out each step, and visualises the decision boundary with `matplotlib`.  
- Students replicate on their own laptops or on the provided cloud notebook.
