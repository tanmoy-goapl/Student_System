## Core Concepts Explanation

### 1. Introduction to SQL
SQL (Structured Query Language) is a standard programming language specifically designed for managing and manipulating relational databases. It is used to perform tasks such as querying data, updating records, and managing database schema. SQL is essential for database administrators, developers, and data analysts.

### 2. Core Components of SQL
SQL can be categorized into several types of commands:

- **Data Definition Language (DDL)**: Commands that define the structure of the database. Examples include:
  - `CREATE`: To create a new table or database.
  - `ALTER`: To modify an existing database object.
  - `DROP`: To delete a table or database.

- **Data Manipulation Language (DML)**: Commands that manage data within the database. Examples include:
  - `SELECT`: To retrieve data from one or more tables.
  - `INSERT`: To add new records to a table.
  - `UPDATE`: To modify existing records.
  - `DELETE`: To remove records from a table.

- **Data Control Language (DCL)**: Commands that control access to data. Examples include:
  - `GRANT`: To give users access privileges.
  - `REVOKE`: To remove access privileges.

- **Transaction Control Language (TCL)**: Commands that manage transactions in a database. Examples include:
  - `COMMIT`: To save changes made during a transaction.
  - `ROLLBACK`: To undo changes made during a transaction.

### 3. Basic SQL Queries
- **SELECT Statement**: Used to query data from a database.
  ```sql
  SELECT column1, column2 FROM table_name WHERE condition;
  ```
- **INSERT Statement**: Used to add new records.
  ```sql
  INSERT INTO table_name (column1, column2) VALUES (value1, value2);
  ```
- **UPDATE Statement**: Used to modify existing records.
  ```sql
  UPDATE table_name SET column1 = value1 WHERE condition;
  ```
- **DELETE Statement**: Used to remove records.
  ```sql
  DELETE FROM table_name WHERE condition;
  ```

### 4. SQL Functions and Clauses
- **WHERE Clause**: Filters records based on specified conditions.
- **ORDER BY Clause**: Sorts the result set in ascending or descending order.
- **GROUP BY Clause**: Groups rows that have the same values in specified columns.
- **Aggregate Functions**: Functions that perform calculations on a set of values. Common functions include:
  - `COUNT()`: Counts the number of rows.
  - `SUM()`: Calculates the total sum of a numeric column.
  - `AVG()`: Calculates the average value of a numeric column.

## In-Class Activities

### Hands-On Practice
**Activity**: Students will be divided into small groups and provided with a dataset (e.g., a simple employee database). Each group will be tasked with writing SQL queries based on the following scenarios:

1. Retrieve all employee names and their departments.
2. Add a new employee record to the database.
3. Update the salary of a specific employee.
4. Delete an employee record based on their ID.
5. Count the total number of employees in each department.

**Instructions**:
- Each group will write their SQL queries on a whiteboard or paper.
- After 10 minutes, groups will present their queries and discuss their thought process.
- The instructor will provide feedback and clarify any misconceptions.
