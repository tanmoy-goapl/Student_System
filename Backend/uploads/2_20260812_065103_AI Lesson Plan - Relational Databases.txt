## Core Concepts Explanation

### 1. Definition of Relational Databases (5-15 minutes)

A relational database is a type of database that stores data in a structured format, using rows and columns. The data is organized into tables, which can be linked—or related—based on data common to each. The relational model was introduced by Edgar F. Codd in the 1970s and has since become the dominant database model due to its simplicity and effectiveness.

**Key Characteristics**:
- **Structured Data**: Data is organized in a tabular format.
- **Relationships**: Tables can be related to one another through foreign keys.
- **ACID Properties**: Ensures reliability in transactions (Atomicity, Consistency, Isolation, Durability).

### 2. Key Components (15-25 minutes)

- **Tables**: The primary structure in a relational database, consisting of rows and columns.
- **Rows**: Each row (or record) represents a single entry in the table.
- **Columns**: Each column represents a specific attribute of the data.
- **Primary Key**: A unique identifier for each row in a table.
- **Foreign Key**: A field in one table that uniquely identifies a row in another table, establishing a relationship.

**Example**: Consider a database for a library. You might have a "Books" table with columns for ISBN, Title, Author, and a "Members" table with MemberID, Name, and Contact. The MemberID in the "Members" table can serve as a foreign key in a "Loans" table to track which member borrowed which book.

### 3. Normalization (25-35 minutes)

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity. It involves dividing large tables into smaller, related tables and defining relationships between them.

**Normal Forms**:
- **First Normal Form (1NF)**: Ensures that all columns contain atomic values and each entry in a column is of the same type.
- **Second Normal Form (2NF)**: Achieved when a table is in 1NF and all non-key attributes are fully functional dependent on the primary key.
- **Third Normal Form (3NF)**: Achieved when a table is in 2NF and all attributes are functionally dependent only on the primary key.

### 4. SQL Basics (35-45 minutes)

SQL (Structured Query Language) is the standard language used to communicate with relational databases. Basic operations include:

- **SELECT**: Retrieve data from a table.
- **INSERT**: Add new records to a table.
- **UPDATE**: Modify existing records.
- **DELETE**: Remove records from a table.

**Example Queries**:
```sql
-- Retrieve all books
SELECT * FROM Books;

-- Insert a new member
INSERT INTO Members (MemberID, Name, Contact) VALUES (1, 'John Doe', '123-456-7890');

-- Update a book's title
UPDATE Books SET Title = 'New Title' WHERE ISBN = '123456789';

-- Delete a member
DELETE FROM Members WHERE MemberID = 1;
```

### 5. Advantages and Disadvantages (45-55 minutes)

**Advantages**:
- **Data Integrity**: Enforced through constraints and relationships.
- **Flexibility**: Easy to query and manipulate data using SQL.
- **ACID Compliance**: Ensures reliable transactions.

**Disadvantages**:
- **Complexity**: Can become complex with large datasets and many relationships.
- **Performance**: May suffer from performance issues with very large datasets or complex queries.
- **Scalability**: Not as easily scalable as some NoSQL databases.

## In-Class Activities

### Activity 1: Group Discussion (10 minutes)

- **Objective**: Encourage students to discuss the advantages and disadvantages of relational databases.
- **Instructions**: Divide the class into small groups. Each group will list at least three advantages and three disadvantages of using relational databases. After 5 minutes, each group will share their findings with the class.

### Activity 2: SQL Query Practice (10 minutes)

- **Objective**: Provide hands-on experience with SQL queries.
- **Instructions**: Provide students with a sample database schema (e.g., Books, Members, Loans). Ask them to write SQL queries to:
  1. Retrieve all books borrowed by a specific member.
  2. Add a new book to the database.
  3. Update the contact information of a member.
  4. Delete a loan record.

### Activity 3: Normalization Exercise (10 minutes)

- **Objective**: Understand the normalization process.
- **Instructions**: Present a denormalized table with redundant data. Ask students to work in pairs to normalize the table up to 3NF and present their normalized tables to the class.
