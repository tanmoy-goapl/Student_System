Course Code: CS304
Course Name: Data Structures & Algorithms
Semester: Fall 2026

Course Objectives:
Master common data structures and algorithmic paradigms.

Course Content:

UNIT 1: Arrays & Strings
- 1D/2D Arrays
- String Matching
- Sliding Window

UNIT 2: Linked Lists
- Singly Linked List
- Doubly Linked List
- Circular Lists

UNIT 3: Stacks & Queues
- Stack Operations
- Queue Implementations
- Applications

UNIT 4: Trees & Graphs
- Binary Trees
- BST
- Graph Traversals (BFS/DFS)

UNIT 5: Sorting & Searching
- Binary Search
- Merge Sort
- Quick Sort

Suggested Books:
- Primary Textbook: Cormen, Leiserson, Rivest, Stein - Introduction to Algorithms
- Reference Book: Mark Allen Weiss - Data Structures and Algorithm Analysis
